# Media attributions

Shark gallery cards and app icons are original FINDS SVG illustrations generated for this repository. They are not NASA logos, not photographs, and not third-party brand marks.

Map tiles in the UI are loaded from OpenStreetMap (`tile.openstreetmap.org`) and remain © OpenStreetMap contributors.

NASA GIBS imagery is used as a data source through documented public APIs; this project does not reproduce the NASA insignia as an app icon.
