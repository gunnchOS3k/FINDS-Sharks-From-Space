**FINDS** (*Fin Identification & Navigation from Satellite*) is an exploratory geospatial platform that uses NASA sea-surface temperature and chlorophyll observations with Gemini-assisted analysis to surface potential shark habitat hotspots. This patch release aligns public documentation and metadata with current production behavior. It does **not** change the live Worker, scoring pipeline, or Android package behavior from v2.0.0.

**Team:** Yasmine Dweir and Edmund Gunn Jr.  
**Award:** NYC Best Use of Gemini API — NASA Space Apps Challenge 2025

## Live production (unchanged from v2.0.0)

- **Web / PWA:** https://finds-web-4j5.pages.dev
- **API:** https://finds-worker.gunnchos-finds.workers.dev

Production continues to use NASA GIBS (MUR Level-4 SST + PACE/VIIRS chlorophyll-a), Cloudflare Worker + R2 cache, Gemini 3.6 Flash, and the Capacitor Android app validated on Pixel 6a.

## No breaking production changes

v2.0.1 is documentation and public-metadata alignment only. No breaking API or deployment changes relative to v2.0.0.

## Scientific disclaimer

FINDS hotspot scores are exploratory research visualizations derived from environmental satellite observations. They are **not** real-time shark warnings and must not be used as a substitute for official marine-safety guidance.
